Problem to solve¶

Suppose we have a set of handwritten digits that we do not know whether they represent 0 or 3, and we want to write a program to classify them into the right group. Or we can say we want to predict the labels of the images.

Suppose we also have some handwritten digits that we do know whether they represent 0 or 3. What we want to do is to make use of the handwritten digits that we already know the labels, to predict those we do not know the labels.

Approach¶

There are many different machine learning models or artificial intelligence tools like convolutional neural network (CNN) for image classification, which one can learn about, for example, in ST311 Artificial Intelligence.

Since ST101A is just a 100-level "programming" course without any formal prerequisite, we will not use any of those methods. Instead, we will do something very simple. For each image whose label we do not know, we compare it with the group of images that we know have label "0" and the group of images that we know have label "3", and see which group the target image is "closer" to. If the target image is "closer" to the group of images with label "0", we predict its label as "0". If not, we predict its label as "3".

How do we know if an image is "closer" to one group than to another? If we can measure the "distance" between images, then we may say a pair of images is "closer" than another pair if their distance is smaller. So if an image has a shorter distance from one group than from another, we can say that the image is closer to that group than to the other.

Distance between 2 images

But how can we measure the distance between 2 images? As we have seen in problem set 1, there can be many different distance measures. Again, we will do something simple (even though the one used below is not a good measurement of distance for images). We calculate the distance of two images $x$ and $y$ by the following:

$$dist(x, y) = \sqrt{\sum_i \sum_j (x_{i,j} - y_{i,j})^2}$$

where $x$ and $y$ represent 2 greyscale images, with $x_{i,j}$ being the pixel value at row $i$ and column $j$ of image $x$.

For example, suppose we have

x = [[1, 0],
     [2, 4]]
y = [[5, 6],
     [10, 8]]

Then $dist(x, y)$ would be $\sqrt{(1-5)^2 + (0-6)^2 + (2-10)^2 + (4-8)^2} \approx 11.489$.

Distance between an image and a group of images

Again we will do something very simple:

$$group\_dist(x, g) = \frac{\sum_{i=1}^{n} dist(x, g_i)}{n}$$

where $g$ is a group of images, $n$ is the number of images in $g$, and $g_1, \ldots, g_n$ are the images in $g$.

For example, suppose there are 3 images in a given group $g$, and we have:

  • Distance between the image $x$ and the first image from the given group $g$ is 11.489
  • Distance between the image $x$ and the second image from the given group $g$ is 6
  • Distance between the image $x$ and the third image from the given group $g$ is 12

The distance between the image $x$ and the given group $g$ would then be $(11.489 + 6 + 12)/3 \approx 9.8297$.
